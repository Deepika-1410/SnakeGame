# 🐍 Snake Game – Java

A simple and interactive Snake Game developed using **Java Swing**.

The player controls the snake using the arrow keys. The snake grows whenever it eats the food, and the game ends when the snake hits the wall or itself.

## 🎮 Features

- Snake movement using arrow keys
- Random food generation
- Score tracking
- Snake grows after eating food
- Wall collision detection
- Self-collision detection
- Game Over screen
- Restart option
- Exit option

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- Git
- GitHub
